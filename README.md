# UnityComfyUIAPIBridge

## 项目介绍

这是一个 Unity 与 ComfyUI 之间的桥接示例工程。它演示了如何在 Unity 端调用 ComfyUI 的 API，完成图像生成、工作流执行等任务的接入与交互，方便快速验证 AI 生成能力在游戏/交互场景中的落地。

## 特性

- 内置 ComfyUI HTTP 客户端与请求/响应类型封装，开箱即用。
- 提供示例场景与可运行的 Demo 脚本，便于理解完整调用链路。

## 如何使用

1. 使用 Unity 2020.3 或更高版本打开本工程。
2. 打开示例场景 `Assets/ComfyUIBridgeDemo/Scenes` 下的场景。
3. 运行 Demo，按脚本中的地址配置连接你的 ComfyUI 服务（默认本地 `http://127.0.0.1:8188`）。
